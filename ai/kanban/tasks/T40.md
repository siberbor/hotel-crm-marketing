# T40 — Backup + Monitoring

## Title
Бэкап БД + мониторинг (Sentry, health endpoint)

## Goal
Система готова к продакшену: ежедневный бэкап PostgreSQL в S3/Minio, реальный health check, Sentry интегрирован.

## Acceptance Criteria
- `/api/health` проверяет DB и Redis реально, возвращает 503 при деградации
- `src/jobs/backup.ts` — pg_dump | gzip → S3/Minio, cron 03:00 ежедневно
- Backup job зарегистрирован в worker process
- Minio добавлен в docker-compose для local dev
- Sentry код готов (нужен DSN в env)

## Agent Context
S3Client через @aws-sdk/client-s3 с forcePathStyle=true для Minio. Health endpoint в src/app/api/health/route.ts. Worker entry: src/workers/start.ts.
