# T36 — Real DB seed

## Title
Real PostgreSQL seed с реальными данными

## Goal
npm run db:seed заполняет реальную PostgreSQL. Убрать зависимость от demo-store в guest/booking/room сервисах.

## Acceptance Criteria
- db:seed создаёт 10 гостей, 10 номеров, 15 бронирований, 5 взаимодействий
- guest.service.ts не падает на пустой БД (без demo-store fallback)
- booking.service.ts, room.service.ts аналогично
- npm run db:seed идемпотентен (можно запускать повторно)

## Agent Context
Сервисы уже пишут в Postgres, но при пустой БД fallback на demoStore. После seed дата реальная. Drizzle schema в src/db/schema.ts.
