# T38 — OpenAPI docs

## Title
OpenAPI спек и страница документации

## Goal
Полный OpenAPI 3.0 спек для всех API эндпоинтов. Страница /api-docs с таблицей и ссылкой на JSON.

## Acceptance Criteria
- GET /api/docs возвращает валидный OpenAPI 3.0 JSON
- Все эндпоинты задокументированы (auth, guests, bookings, rooms, interactions, campaigns, segments, search, channels, reports, notifications, health)
- /api-docs страница показывает таблицу эндпоинтов с методами и описаниями
- Кнопка "OpenAPI JSON ↗" открывает raw спек
- PATCH /api/auth/me (onboarding) включён

## Agent Context
Спек хранится в src/app/api/docs/route.ts как JS-объект. Страница в src/app/api-docs/page.tsx.

- src/app/api-docs/page.tsx
