# T31 — Sentry error monitoring

## Title
Sentry мониторинг ошибок

## Goal
Sentry интеграция для фронтенда и бэкенда. Алерты на критические ошибки.

## Acceptance Criteria
- @sentry/nextjs установлен и настроен
- Ошибки фронтенда автоматически отправляются в Sentry
- API errors (5xx) логируются с контекстом
- Source maps загружаются при build
- DSN в .env (SENTRY_DSN)

## Agent Context
SENTRY_DSN из .env. Не логировать PII (email, телефон). Sentry.init только если DSN задан.
