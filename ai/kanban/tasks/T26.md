# T26 — Email sending with Resend API

## Title
Email интеграция (Resend API)

## Goal
Отправка email через Resend API. Используется в кампаниях и уведомлениях.

## Acceptance Criteria
- Resend SDK подключён
- EmailService с методами: sendCampaign(campaignId), sendBookingConfirmation(bookingId)
- HTML шаблоны для писем
- Обработка ошибок и логирование

## Agent Context
