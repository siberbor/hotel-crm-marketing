# T43 — Onboarding Tour

## Title
Онбординг тур для admin при первом входе

## Goal
После первого входа admin проходит интерактивный тур по ключевым экранам (react-joyride уже в зависимостях).

## Acceptance Criteria
- Тур запускается автоматически для admin если onboardingCompleted===false
- Шаги: Dashboard → Guests → Bookings → Campaigns → Settings
- Кнопки "Далее", "Пропустить", "Завершить"
- После завершения/пропуска вызывается PATCH /api/auth/me (T39 уже реализован)
- Тур не показывается повторно
