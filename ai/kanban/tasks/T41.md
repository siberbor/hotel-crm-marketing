# T41 — Channel Manager Integration

## Title
Интеграция с Channel Manager (Booking.com, Airbnb)

## Goal
Бронирования из внешних каналов синхронизируются автоматически без конфликтов через BullMQ очередь.

## Acceptance Criteria
- Входящие бронирования из Booking.com / Airbnb создаются в bookings таблице
- Конфликты дат блокируются — не создаются дублирующие бронирования
- Каждая операция логируется в sync_logs
- Sync worker не блокирует main thread (BullMQ)
- Hourly full sync + 15min rate push уже запланированы (scheduled-sync.ts)

## Agent Context
BullMQ queue: src/lib/queues.ts. Workers: src/workers/sync.worker.ts. Scheduled jobs: src/jobs/scheduled-sync.ts. sync_logs таблица в schema.ts. ADR-004: BullMQ только для channel sync.
