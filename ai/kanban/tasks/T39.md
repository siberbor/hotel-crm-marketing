# T39 — Onboarding complete flow

## Title
Онбординг: завершение и редирект новых пользователей

## Goal
Новые пользователи автоматически попадают на /onboarding. После завершения/пропуска — onboarding_completed сохраняется в БД.

## Acceptance Criteria
- PATCH /api/auth/me устанавливает onboarding_completed=true
- GET /api/auth/me возвращает onboardingCompleted в ответе
- AppShell редиректит на /onboarding если onboardingCompleted===false
- Кнопки "Завершить" и "Пропустить" вызывают PATCH перед router.push
- Graceful при отсутствии БД (best-effort)

## Agent Context
users.onboardingCompleted уже в схеме Drizzle. AppShell в src/components/AppShell.tsx. Избегать редирект-loop когда уже на /onboarding.
