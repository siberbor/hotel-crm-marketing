🚀 Памятка по Workflow

1

Загрузи задачу из Kanban

Кликни на задачу со статусом To Do. Прочитай goal, acceptance criteria, agent context.

2

Проверь зависимости

Убедись, что все зависимые задачи имеют статус Done. Если нет — STOP.

3

Запусти CLI Runner

node ai/bin/run.js --task T## — создаст сессию. Или --dry-run для предпросмотра.

4

Planner → декомпозиция

Разбей на backend, frontend, db, tests. Определи параллельность.

5

Worker-агенты → реализация

Backend (Fastify+Zod) + Frontend (Next.js+React Query). Читай существующий код перед написанием.

6

QA → тестирование

npm run test + npm run test:api + npm run lint:fix

7

Review → валидация

Architecture, security (RBAC), performance. Verdict: APPROVED / CHANGES_REQUIRED.

8

Обнови Kanban и Memory

Перетащи задачу в Done на доске. Обнови ai/memory/context.md, decisions.md, сессию.

💻 CLI Commands

node ai/bin/run.js --statusСтатус канбана

node ai/bin/run.js --dry-runПредпросмотр следующей
node ai/bin/run.js --task T12Запустить задачу T12
node ai/bin/kanban-sync.js --validateПроверить консистентность
npm run lint:fix && npm run testЛинт + тесты

⚠️ Hard Rules

• Не обходи RBAC middleware
• Не хардкодь секреты
• Не запускай миграции без подтверждения
• Не изменяй AGENTS.md — только дополняй
• Читай существующий код перед написанием
• Запускай lint + test перед завершением
• AGENTS.md — единственный источник правды
