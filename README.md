# Hotel CRM — Agent Documentation System

Полный пакет документации для мульти-агентной разработки CRM системы отеля.

## Файлы и их назначение

```
AGENTS.md                      ← Универсальный контекст (все агенты читают это)
CLAUDE.md                      ← Claude-специфичный контекст (импортирует AGENTS.md)
skill/SKILL.md                 ← Протокол выполнения задач (8 шагов)
docs/
  sprints/
    sprint-plan.md             ← Все 5 спринтов, 18 задач, зависимости
    current-sprint.md          ← Текущий спринт (агенты обновляют)
    session-log.md             ← Лог сессий (агенты дописывают в конце)
  decisions/
    README.md                  ← ADR (Architecture Decision Records)
```

## Быстрый старт для каждого агента

### Claude Code
```bash
# CLAUDE.md подхватывается автоматически
claude "Возьми задачу T06 — модуль бронирований"
```

### Qwen Code / OpenCode
```bash
# Передай AGENTS.md в контекст
cat AGENTS.md | qwen "Прочитай этот контекст, затем возьми задачу T07"
```

### GPT-4o через оператора
```
System prompt (оператор вставляет):
[содержимое AGENTS.md]

User message:
Возьми задачу T08 — Email-маркетинг кампании.
Текущий статус: Sprint 3. Зависимость T12 Done.
```

## Правила обновления документации

- **AGENTS.md** — обновляет человек или агент при изменении стека/правил
- **current-sprint.md** — агенты обновляют статусы задач
- **session-log.md** — агенты дописывают в конце КАЖДОЙ сессии
- **decisions/README.md** — агенты добавляют ADR при нетривиальных решениях
- **sprint-plan.md** — только человек (плановый документ)
